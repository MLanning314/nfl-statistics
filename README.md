## Setup of Project

### Description of Project
This project analyzes historical data from the NFL to gain insights into team performance, trends, and key variables that influence total wins. The dataset includes information on various team statistics, such as points scored, points allowed, wins, penalties, and touchdowns across multiple seasons.

The goal of this project is to provide a comprehensive understanding of the factors influencing team success, and offer insights that could guide future strategies in the National Football League.

### Setup of Repository
The main file for this project can be found under "Lanning_Mackenzie_final_report", along with a shorter summary under "Lanning_Mackenzie_executive_summary". There are labeled RScripts where data cleaning, exploratory data analysis, and figure polishing were conducted. All figures for this project can be found in the "figures" folder, and the data, both raw and cleaned, can be found in the "data" folder. The dataset specifically used for this project can be found under "nfl_data_clean" in the data folder. 

This project also contains two progress memos in the repository that show the progress of this project, but these are not necessary to understand the final project. 

The author and maintainer of this dataset is Mackenzie Lanning (myself) - if there are any questions or concerns about this dataset they can be directed to me. Additionally, the original dataset was found on [Kaggle](https://www.kaggle.com/datasets/nickcantalupa/nfl-team-data-2003-2023/data?select=team_stats_2003_2023.csv) by author Nick Cantalupa
